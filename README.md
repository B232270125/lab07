## Дүгнэлт (debrief)

Хамгийн үр дүнтэй нь Couch Potato аялал байв: UI-аар хоосон, буруу, хилийн утгатай оролтоор ном нэмж, хайж явахдаа BUG-01 (хоосон Гарчиг/Зохиолчтой ном нэмэгдэж, Он=0 болдог), BUG-02 (Он-д abc, 999, 0, 19.5, -5 хүлээн авагддаг), BUG-03 (Он таслалтай харагддаг, жишээ нь 1,999), BUG-04 («Нийт ном» тоолуур хүснэгтийн мөрөөс 1-ээр илүү), BUG-05 (хайлт том/жижиг үсэг ялгадаг), BUG-06 (200+ тэмдэгттэй гарчиг хүснэгтийг өндөр болгодог)-ыг олсон. Мөн давхардсан номыг татгалздаггүй (BUG-07), `<b>test</b>` оролт хүснэгтэд `&lt;b&gt;` хэлбэрээр харагддаг (BUG-09) зэргийг charter-ын дагуу шалгахдаа олсон. Saboteur аялал API түвшинд BUG-11 (дутуу JSON-д 400 биш 200 OK буцаадаг)-ыг илрүүлсэн нь UI-аар огт харагдахгүй согог байсан тул энэ аялал өөр төрлийн согог олсноороо үнэ цэнэтэй. Charter-аас гадуур, өөр зүйл шалгаж байхдаа анзаарсан зүйл бол Устгах товч улаан биш ногоон өнгөтэй байсан (cosmetic), ном нэмэх, устгахад мессеж зөв өөрчлөгддөггүй (BUG-08), нүүр хуудасны "Хуучин хувилбар" линк дээр сервер 500 Internal Server Error буцаадаг (BUG-10) явдал юм. Дараагийн session-д шалгагдаагүй үлдсэн зүйлс: Он=2101 хилийн утга, үйлдэл бүрийн дараах мессежийн үсгийн алдаа, устгасны дараах тоолуурын зан төлөв, API-ийн GET, DELETE endpoint-ууд, эдгээр нь дараагийн charter-ын сэдэв болно. Лаб 1-ийн Playwright автомат тестээр BUG-04 (мөрийн тоо ба тоолуурыг харьцуулах assert), BUG-05 (`clean`, `CLEAN` хайлтын үр дүн), BUG-01, BUG-02 (буруу оролтыг татгалзах эсэх) зэргийг найдвартай барих байсан, учир нь хүлээгдэж буй үр дүн нь тодорхой, шалгахад хялбар. BUG-11 болон 500 алдааг (BUG-10) ч тестэд API хүсэлтийн статус код шалгаснаар автоматаар барьж болно. Харин Устгах товчийн өнгө болон BUG-06 (урт гарчигтай үед хүснэгтийн байршил эвдрэх) нь визуал шинжтэй тул зөвхөн хүний нүдээр олдох байсан, харин BUG-03 (1,999 гэх таслал) нь тусгайлан assert бичсэн тохиолдолд л автоматаар баригдана. Дүгнэж хэлбэл, автомат тест урьдчилан мэдэж байгаа дүрмийг шалгахад сайн, хүний судалгааны туршилт урьдчилан тааварлаагүй согогийг олоход сайн тул хоёр арга бие биеээ нөхдөг.
