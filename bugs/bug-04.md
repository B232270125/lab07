# BUG-04: Нүүр хуудсанд «Нийт ном» тоолуур хүснэгтэд буй номын тооноос 1-ээр илүү харагддаг



Орчин: Уншлагын жагсаалт v2.0, Chrome, Windows 11 Pro 25H2, 2026-10-16



Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)



## Дахин гаргах алхам



1. PowerShell-д `node app.js` ажиллуулна (шинээр асаасан байх ёстой).

2. Браузерт http://localhost:3000 хаягийг нээнэ.

3. Хүснэгтэд харагдаж буй мөрийг тоолно.

4. Хүснэгтийн доорх «Нийт ном» тоог харна.



Хүлээгдэж байсан: «Нийт ном» тоолуур хүснэгтэд буй номын тоотой тэнцүү (спецификаци: «"Нийт ном" тоолуур хүснэгтэд буй номын тоотой тэнцүү»), өөрөөр хэлбэл 3.



Бодит үр дүн: Хүснэгтэд 3 мөр (Тунгалаг Тамир, Clean Code, The Pragmatic Programmer) харагдана, харин «Нийт ном: 4» гэж гарна. Зөрүү үргэлж 1 байна: сесс дээр ном нэмсэний дараа ч 7 мөр дээр «Нийт ном: 8», 15 мөр дээр «Нийт ном: 16» гэж харагдсан.



Ноцтой байдал: Major. Хэрэглэгчид үзүүлж буй тоо буруу бөгөөд спецификацийн шууд зөрчил, мөн нүүр хуудас нээсэн даруйд харагддаг тул хэрэглэгч бүрт нөлөөлнө. Өгөгдөл алдагдахгүй тул Critical биш.
