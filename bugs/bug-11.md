\# BUG-11: POST /api/books руу буруу (дутуу) JSON илгээхэд сервер 400 биш, `200 OK` буцаадаг



Орчин: Уншлагын жагсаалт v2.0, curl.exe (Windows PowerShell), Windows 11 Pro 25H2, 2026-10-16



Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)



\## Дахин гаргах алхам



1\. PowerShell-д `node app.js` ажиллуулна (шинээр асаасан байх ёстой).

2\. Өөр PowerShell цонх нээж, төслийн хавтас руу орно: `cd $HOME\\Documents\\lab07`

3\. Санаатайгаар дутуу (хаагдаагүй) JSON-тай файл үүсгэнэ:

&#x20;  `'{"title": "Тест", "author": ' | Set-Content -Encoding ascii body.json`

4\. Хүсэлт илгээнэ:

&#x20;  `curl.exe -s -i -X POST http://localhost:3000/api/books -H "Content-Type: application/json" --data-binary "@body.json"`

5\. Хариуны эхний мөр (статус) болон биеийг харна.



Хүлээгдэж байсан: Спецификаци: «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана». Тиймээс `HTTP/1.1 400 ...` байх ёстой.



Бодит үр дүн: Сервер `HTTP/1.1 200 OK` буцаана, биед нь `{"result":"OK"}` байна. Буруу хэлбэртэй JSON-г алдаагүй хүлээн авсан мэт хариулж байна.



Ноцтой байдал: Major. API нь буруу оролтыг татгалзахгүй, клиентэд амжилттай гэж худал мэдээлдэг тул дуудагч тал алдаагаа мэдэхгүй. Апп унахгүй, өгөгдөл эвдрэхгүй тул Critical биш.
